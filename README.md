# Dafa Afandi Portfolio

Portfolio pribadi Muhammad Abi Dafa Afandi, built with React, Vue 3, and Vite.

## Stack

- React for the main application layout and page state.
- Vue 3 Composition API for the reusable project photo slider.
- Vite for development and production builds.
- Plain CSS for the visual system and responsive layout.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/` and is ready for static hosting such as Vercel.

## Project structure

```text
src/
├── components/    React components and the Vue bridge
├── data/          Portfolio project data
├── styles/        Portfolio stylesheet
├── vue/           Vue 3 components
├── App.jsx
└── main.jsx
public/
├── images/        Portfolio images

```
